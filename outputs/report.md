## 3 机制、不稳定与责任划分（实验 e3）

### 3.1 机制：解在特征方向上怎么分配

把 x = Σ⁻¹μ 按 Σ 的特征向量展开：x = Σᵢ cᵢvᵢ，cᵢ = (vᵢᵀμ)/λᵢ。特征值越小，同一个 μ 投影被除得越大。

- 真实矩阵：最大的 3 个方向承担 ‖x‖² 的 39.8%；
- 样本矩阵：最大的 3 个方向承担 **94.5%**，而这 3 个方向恰好是 λ 最小的 3 个——也就是噪声方向。

### 3.2 换一段数据，答案就翻（图 5a）

同一市场、两段独立的 60 天数据、同一个优化器：两个权重向量的相关系数是 **-0.03**，换手率 0.70。也就是说，两份同样合法的数据给出两个几乎无关的组合。

读这张表有两个容易踩的坑。第一，“1% 扰动引起的放大”在 N≥45 之后进入平台（N=50 是 169、N=55 是 155，两点差在 1 个标准差之内），不要读成单调下降——一阶近似在大 κ 下已经失效，响应饱和；还在涨的是“解的实际相对误差”那一列（367 → 1248）。第二，“误差/界”那一列是解的相对误差除以界，不是放大倍数除以 κ，两者数值接近但含义不同。

### 4.3 为什么 μ 修不动

T=60 时单个资产均值的 t 统计量：中位数 |t| = 0.66，|t|>2 的比例 4.5%（图 7d）。整条均值向量在统计上和一条常数没有区别，优化器拿它做的就是拟合噪声。
