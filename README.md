## 1 这个程序在证明什么

全篇只有一句话：

> **数学上"最优"的组合，现实中可能最不可靠，因为求逆把估计误差放大了。**

程序把这个句子拆成五个可以运行、可以核对的步骤：

| 步骤 | 数学命题 | 程序怎么验证 |
|---|---|---|
| 1 | 最优权重 w ∝ Σ⁻¹μ，中间有一次**矩阵求逆** | 解线性方程组，记录权重 |
| 2 | 求逆会把小特征值变成大数：‖Σ⁻¹‖ = 1/λ_min | 量 κ(Σ) 和 λ_min，真值 vs 估计值 |
| 3 | 估计误差经过求逆被放大 κ 倍 | 给 Σ 加 1% 扰动，量解变了多少；与 κ 对照 |
| 4 | 结果：权重极端、对数据极敏感、换一段数据就翻 | 扫 N、比两段独立样本、算两本书的相关系数 |
| 5 | 修补：收缩 Σ、弃用或收缩 μ | 2×2 因子设计，看哪个修补修的是"风险"、哪个修的是"方向" |

### 一个关键设计：为什么要用"已知真值"的模拟市场

论文的问题是"**估计出来的组合离真实最优组合有多远**"。这个问题只有在真 Σ、真 μ
已知时才回答得了。真实数据里它们未知，任何关于"误差放大"的说法都只能是间接的。

所以程序用了一个**校准过的三因子模型**当数据生成过程：

```
r_t = B f_t + ε_t,   ε_t ~ N(0, D),  D 对角
μ_true   = B μ_f + α
Σ_true   = B Σ_f Bᵀ + D
```

校准目标是美股日频的典型事实（市场因子 16% 年化波动、特质波动 15–32%、
平均两两相关 0.3、因子溢价 1–7%、α 截面离散度 2%）。**这不是"造假数据"**，
而是收缩估计文献（Ledoit-Wolf 2004、DeMiguel et al. 2009）的标准做法：
要先分离"估计误差"和"模型误差"，必须有真值。

程序里同时保留了两类量：

- **真值类**（μ_true、Σ_true、真实夏普）：只在评估时用，绝不出现在优化器的输入里；
- **估计类**（μ̂、Ŝ、Ledoit-Wolf Σ̃）：优化器能看到的全部信息。

这个隔离在代码里是硬性的：`estimators.estimate()` 只接受收益率面板，
`analysis.population_sharpe()` 只接受真值。想让优化器"偷看"真值，得改代码。

### 第二个关键设计：为什么要重复 30 次

单一抽样在这个问题里**完全不可用**。同样是 N=55、T=60，换一段 60 天数据，
直接代入的组合夏普能在 −0.07 和 +0.04 之间跳。这个幅度和要测的效应一样大。

所以每个统计量都是 **30 次独立重复的均值**，每次重复重新抽一个市场 + 一段估计窗口。
图上阴影是 ±1 个标准差——两条线的差距如果小于阴影宽度，就不该写进论文。

## 4 五个实验逐一说明

### e1 · 病态从哪里来（对应论文第 3 章）

**问什么**：真实的协方差是良态的，估计出来的不是吗？差多少？

**怎么做**：对每个重复、每个 N，抽 60 天数据，算 κ(Σ_true)、κ(Ŝ)、κ(收缩后)，
以及最小特征值。再固定 N=30 把 T 从 40 拉到 2400。

**结果**：

| N | κ(Σ) 真 | κ(Ŝ) 样本 | κ(Ledoit-Wolf) | λ_min 真 | λ_min 样本 |
|---|---|---|---|---|---|
| 5 | 5.0 | 6.6 | 4.8 | 1.57e-04 | 1.23e-04 |
| 30 | 35.2 | 182 | 42.2 | 9.80e-05 | 2.01e-05 |
| 55 | **65.2** | **12804** | 98.2 | 9.40e-05 | **6.06e-07** |

一句话：N=55 时样本矩阵的最小特征值只剩真值的 **0.6%**，条件数涨了 **196 倍**。

T 方向：N=30 时 T 从 60 涨到 2400，κ 从 202 降到 36.6——**但降不到 1**，
因为真实矩阵本身就有结构（3 个因子 + 对角噪声），κ(Σ) 是下界。

**产物**：`fig1_spectrum.png`、`fig2_conditioning.png`、`e1_conditioning.csv`

`fig2(b)` 是这一章最直观的一张：横轴真特征值、纵轴样本特征值，按秩配对。
大特征值贴在 y=x 上（估得准），小特征值全部掉到 y=x 下面（被压向 0）。
**"求逆等于除以一个接近 0 的数"，在图上就是那一列掉下去的点。**

### e2 · 权重爆炸（对应论文第 4 章前半）

**问什么**：矩阵病态，会传到权重上吗？

**怎么做**：**2×2 因子设计**——协方差用原始还是 Ledoit-Wolf，目标里用不用 μ：

|  | 用 μ | 不用 μ |
|---|---|---|
| 原始 Ŝ | 直接代入解 | 最小方差（原始） |
| 收缩 Σ̃ | 收缩 Σ | 最小方差（收缩） |

每个组合都缩放到 **15% 年化波动**（用它自己相信的协方差缩放），杠杆 = 每单位净值需要的总敞口。

**为什么用波动率目标而不是"权重和为 1"**：强制 1ᵀw=1 要除以 1ᵀΣ⁻¹μ，
这个标量会随机穿过 0，杠杆曲线会变成纯噪声（实测：N=15 是 7，N=20 是 27，
N=55 突然 603）。波动率目标口径下曲线单调、可解释，而且夏普与缩放无关，
所以这个选择不会偏袒任何一方。

**结果**（N=55，T=60）：

| 策略 | 杠杆 Σ\|wᵢ\| | 最大单一仓位 | 真实波动 | 真实夏普 |
|---|---|---|---|---|
| 原始 Σ + μ | **54.75** | 320% | **212%** | 0.022 |
| 收缩 Σ + μ | 5.71 | 33% | 22% | 0.032 |
| 原始 Σ，不用 μ | 52.23 | 325% | — | 0.077 |
| 收缩 Σ，不用 μ | 5.19 | 32% | — | 0.255 |

读法：

1. 杠杆随 N 从 1.23（N=5）涨到 54.75（N=55），**45 倍**；
2. 只把 Σ 换成 Ledoit-Wolf，杠杆掉到 5.71（−89.6%）；
3. **光把 μ 扔掉几乎没用**（52.23）——病态的是 Σ⁻¹，不是 μ；
4. 两件事一起做才回到 5.19。

**最要紧的一列是"真实波动"**：直接代入解自认为在跑一个 15% 波动的组合，
真实波动是 **212%**。它不是"风险高"，它是**把风险算错了**——
这正是 Michaud 说的 error maximization。

这个 14.1 倍的低估（212/15）不是孤立数字，它和最小特征值的塌缩是同一个东西的两种说法：
λ_min 塌了 **155 倍**，而组合波动大致按 1/√λ_min 放大，√155 ≈ **12.4**，
和 14.1 同一数量级。所以"风险被低估 14 倍"的根源就是"λ_min 塌了两个数量级"——
论文里把这两个数字并排放，比单独摆一个 212% 有说服力得多。

> 数字统一：λ_min 比 6.45e-03 的倒数是 **155**（精确值 9.40e-05 / 6.06e-07 = 155.1）。
> 断言表里因为四舍五入显示 0.0064，反算是 156——**论文里统一写 155**，别混用。

**产物**：`fig3_leverage.png`、`e2_leverage.csv`

### e3 · 机制、不稳定与责任划分（对应论文第 3、4 章）

这一节回答三个问题。

**（a）机制：解在特征方向上怎么分配**

把 x = Σ⁻¹μ 按 Σ 的特征向量展开：

```
x = Σ_i c_i v_i,   c_i = (v_iᵀμ) / λ_i
```

特征值越小，同一个 μ 投影被除得越大。实测：

- 真实矩阵：‖x‖² 的 **39.8%** 落在前 3 个方向；
- 样本矩阵：**94.5%** 落在前 3 个方向，而这 3 个方向恰好是 λ 最小的 3 个
  ——也就是噪声方向。

**（b）换一段数据，答案就翻**

同一市场、两段独立的 60 天数据、同一个优化器：两个权重向量的相关系数是 **−0.03**，
换手率 0.70。两份同样合法的数据给出两个几乎无关的组合。

**（c）责任划分：到底是 μ 还是 Σ**

把其中一个矩换成真值，看夏普能恢复多少：

| N | 上帝视角 | 已知 μ，只估 Σ | 已知 Σ，只估 μ | 两者都估 |
|---|---|---|---|---|
| 5 | 0.380 | 0.368 | 0.092 | 0.081 |
| 30 | 0.652 | **0.462** | 0.008 | −0.021 |
| 55 | 0.820 | 0.253 | 0.028 | 0.022 |

结论很干净：**把 μ 换成真值，夏普从 0.022 升到 0.253（11 倍）；把 Σ 换成真值，
只升到 0.028（1.3 倍）。夏普的瓶颈在 μ，不在 Σ。**

> 注意别读反：是「知道 μ」值钱，不是「知道 Σ」值钱。原因在下一段——
> μ 的相对误差是 Σ 的 21 倍，同一台放大器（κ）放大之后，μ 那一项在量级上压过 Σ。

为什么？量一下两个输入的相对误差：

```
ε_μ = ‖μ̂ − μ‖ / ‖μ‖  ≈ 8.27      （827%）
ε_Σ = ‖Ŝ − Σ‖_F / ‖Σ‖_F ≈ 0.40    （40%）
```

**均值向量的相对误差是协方差矩阵的 21 倍。** 两者的误差被同一个 κ 放大，
所以 μ 那一项在量级上压过 Σ。

> 严格说，两项不是同一个量纲：δΣ 作用在 x 上，δμ 直接进方程，真正要比的是
> ‖δΣ·x‖ 和 ‖δμ‖，不是 ε_Σ 和 ε_μ。但在这个设定下两者相差 21 倍，
> 数量级的差距足以盖过量纲上的差别，所以结论是「量级上压过」，
> 不要写成「必然压过」——答辩时被追问「凭什么必然」，这一条不好答。

**（d）放大倍数与一阶界**

给 Ŝ 加一个相对 Frobenius 范数为 1% 的随机对称扰动，量解变了多少：

| N | κ(Ŝ) | 1% 扰动引起的放大 | 解的实际相对误差 |
|---|---|---|---|
| 5 | 6.6 | 1.9 | 18.2 |
| 30 | 182 | 10.8 | 57.5 |
| 55 | 12804 | **155** | **1248** |

一阶扰动理论给出

```
‖δx‖/‖x‖  ≤  κ(Ŝ) · ( ‖δμ‖/‖μ‖ + ‖δΣ‖/‖Σ‖ )
```

**这里的常数是 κ(Ŝ)，不是 κ(Σ)。** 这一条容易被写成 κ(Σ)，一写就错：

- 被求逆的矩阵是 **Ŝ**，不是真 Σ。一阶展开 `δx ≈ −Ŝ⁻¹(δΣ)x − Ŝ⁻¹(δμ)`
  里出现的是 `‖Ŝ⁻¹‖·‖Ŝ‖ = κ(Ŝ)`，所以界里的常数天然就是 κ(Ŝ)；
- **验算就能看出差别**：N=55 时解的实际相对误差是 1248、ε_μ+ε_Σ = 8.67
  （两者都是相对量、同一尺度，可以直接比，不是百分数）。
  用 κ(Ŝ)=12804 算，1248/(12804×8.67) = **0.011**，界成立；
  用 κ(Σ)=65.2 算，1248/(65.2×8.67) = **2.21 > 1**，界直接被违反。

所以「界成立」这件事只在 κ(Ŝ) 下才成立。实测误差与这个界之比从 0.35（N=5）
降到 0.011（N=55）——**界成立，但保守**：随机扰动只激发最坏方向的约 1/N。

> 顺带说明：κ(Σ)=65 和 κ(Ŝ)=12804 差 196 倍，恰好就是本文要讲的那件事。
> 用 κ(Σ) 去写界，等于默认"估计没有把矩阵搞坏"，而这正是全文要否定的前提。

两个容易踩的坑：**（i）**"1% 扰动引起的放大"在 N≥45 后进入平台（N=50 是 169、N=55 是 155，
差在 1 个标准差内），不是单调曲线，别画成下翘后还去解释它；还在涨的是"解的实际相对误差"
（367 → 1248）。**（ii）**"误差/界"= 解的实际相对误差 ÷ 界，不是放大倍数 ÷ κ，两者数值接近但含义不同。

**产物**：`fig4_mechanism.png`、`fig5_instability.png`、`fig6_amplification.png`、
`e3_decomposition.csv`、`e3_amplification.csv`、`e3_two_sample.csv`

### e4 · 两种修补（对应论文第 4 章后半）

**（a）收缩 Σ 有多管用**

| δ_Σ | 杠杆 | 夏普 |
|---|---|---|
| 0.00 | 54.75 | 0.022 |
| **0.15（最接近 LW 的 0.169）** | **5.90** | **0.035** |
| 0.50 | 3.64 | 0.022 |
| 0.99 | 2.99 | 0.018 |

Ledoit-Wolf 的强度是 δ = **0.169 ± 0.042**。它的判据是让 E‖Σ̃−Σ‖² 最小
——这对**估计**一个矩阵是最优的，但对**求逆**并不够：一路加到 0.99，杠杆还能再降一半。

**这是全篇最实用的一条：Ledoit-Wolf 的强度不该直接拿来当正则化强度。**
两个目标不同：前者问"矩阵估得准不准"，后者问"求逆之后稳不稳"。

**（b）把 μ 收缩掉**

在权重空间把直接代入解朝最小方差方向混合（δ_w = 0 是直接代入，δ_w = 1 是最小方差）：

| δ_w | 杠杆 | 夏普 |
|---|---|---|
| 0.0 | 5.71 | 0.032 |
| 0.5 | 5.36 | 0.220 |
| 1.0 | 5.19 | 0.255 |

**夏普从 0.032 升到 0.255，杠杆几乎不动（5.71 → 5.19）。**

为什么在权重空间做，而不是在 μ 空间"向均值收缩"？因为 T=60 时样本均值的
截面均值本身是个掷硬币：它的标准误约 1.4e-3/日，信号只有 2.6e-4/日，
大约一半的样本里估计出来的截面均值是**负数**。朝一个负常数收缩会让整个组合翻符号，
"修补"出来的东西是做空最小方差组合——那是估计量的伪影，不是组合。
权重空间的凸组合是同一件事的良定版本（Jagannathan & Ma 2003：约束权重与收缩均值等价）。

**（c）为什么 μ 修不动**

T=60 时单个资产均值的 t 统计量：中位数 |t| = **0.66**，|t|>2 的比例 **4.5%**
（正态零假设下本来就该是 5%）。整条均值向量在统计上和一条常数没有区别，
优化器拿它做的就是拟合噪声。

**产物**：`fig7_shrinkage.png`、`e4_shrinkage.csv`、`e4_intensity.csv`

### e5 · 样本外（对应论文第 5 章）

**问什么**：以上都是关于估计误差的陈述。投资人只关心修补之后组合是不是真的更好。

**两个尺子**：

- **真实夏普** = wᵀμ_true / √(wᵀΣ_true w)：权重的性质，无抽样噪声，是理论谈的那个数；
- **实现夏普**：在独立 2000 天路径上的均值，只用来确认前者不是编出来的。

**结果**（N=55，T=60）：

| 策略 | 真实夏普 | 实现夏普 | 杠杆 | 最大单一仓位 |
|---|---|---|---|---|
| 上帝视角（真 μ、真 Σ） | **0.820** | 0.787 | 3.49 | 27% |
| 直接代入解 | 0.022 | −0.051 | 54.75 | 320% |
| 收缩 Σ | 0.032 | −0.001 | 5.71 | 33% |
| 最小方差（原始 Σ） | 0.077 | 0.130 | 52.23 | 325% |
| 最小方差 + 收缩 Σ | 0.255 | 0.387 | 5.19 | 32% |
| 最小方差 + 长仓约束 | 0.340 | 0.421 | 1.51 | 31% |
| **1/N** | **0.396** | 0.423 | 0.95 | 2% |

一句话：**在这个样本长度下，1/N 打败所有优化模型**——这就是 DeMiguel、Garlappi
和 Uppal (2009) 的结论在本文设定下的复现。

**要多少数据才够**（固定 N=55）：

| T | T/N | 直接代入解夏普 | 直接代入解杠杆 | 1/N |
|---|---|---|---|---|
| 60 | 1.1 | 0.027 | 61.2 | 0.396 |
| 600 | 10.9 | 0.123 | 4.2 | 0.396 |
| 2400 | 43.6 | 0.245 | 3.9 | 0.396 |

拉到约 9.5 年（T/N=44），直接代入解才爬到 0.245，**仍明显低于 1/N**。
这就是"均值难估"在时间维度上的代价。

## 7 与《选题确认.md》的四处出入（写作前必读）

原方案里有四处数字或说法，跑完程序后需要修正。**这不是程序错了，是原方案的简化
在完整实验里不成立**，而这几处恰好都是可以在论文里加分的讨论点。

### ① 杠杆的量级完全不同（12.5/37.8/68.1 → 1.23/…/54.75）

原方案表格：N=5 是 12.5，N=55 是 68.1。本程序：N=5 是 1.23，N=55 是 54.75。

原因有三条，都要在论文里交代：

1. **杠杆口径不同**。原方案用"权重和为 1"，本程序用"波动率目标 15%"。
   前者要除以 1ᵀΣ⁻¹μ，那个标量会随机穿零，单次抽样的杠杆因此不可复现；
2. **市场校准不同**。原方案的数字来自另一套参数；
3. **单次抽样 vs 30 次重复**。原方案是一次抽样，本程序是均值。

**写法**：正文写"杠杆从 1.23 涨到 54.75，涨 45 倍"，并明确口径是
"每单位净值在 15% 波动目标下需要的总敞口"。这个口径比"权重和为 1"稳得多，
也更好解释。

### ② "μ 比 Σ 更致命"这句话要拆成两句

原方案："只修 Σ 只能把杠杆从 68 降到 37（减半，不够）；再修 μ 才降到 4。
两个误差源，μ 比 Σ 更致命。"

本程序的结果是：**对杠杆，Σ 是全部；对夏普，μ 是全部。**

| 症状 | 主要来源 | 证据 |
|---|---|---|
| 杠杆爆炸、风险被低估 | **Σ** 的病态 | 只收缩 Σ，杠杆 54.75 → 5.71；只弃用 μ，杠杆仍 52.23 |
| 组合方向错、夏普归零 | **μ** 的噪声 | 已知 μ 只估 Σ：夏普 0.253；已知 Σ 只估 μ：夏普 0.028 |

**写法**：这比原方案的一句话更有分量，因为它是**两个正交的结论**，
而且各自有一个干净的实验支撑。第 5 章讨论可以这样开头：
"病态性有两个症状，它们来自两个不同的误差源，需要两种不同的修补。"

**再往前一步（建议写进第 5 章末尾，能收住全文）**：把表 4 和表 9 放在一起看，
其实是一条**瓶颈转移**的故事，比"两个正交结论"更有收束力：

| 数据量 | Σ 的状态 | μ 的状态 | 结果 |
|---|---|---|---|
| T/N ≈ 1（60 天） | 病态，杠杆 54.75 | 噪声，夏普 0.022 | 两个病都发作 |
| T/N ≈ 44（9.5 年） | **已修好**，杠杆 3.9 | 还是噪声 | plug-in 夏普 0.245，**仍输给 1/N 的 0.396** |

一句话：**Σ 的病态是急性病，加数据能治；μ 的不可估是慢性病，加数据治不好。**
这句话有表 9 的 6 行数据撑着（T 从 60 拉到 2400，夏普从 0.027 爬到 0.245，始终够不着 0.396），
比只说"两个独立结论"更难被追问。

### ③ "收缩 Σ + μ → 4.17" 在统计上做不到

原方案：收缩 Σ 再收缩 μ，杠杆降到 4.17。本程序：Jorion 型的均值收缩在 T=60 时
不可用——截面均值本身是负数（约一半样本），朝它收缩会让组合翻符号。
改用权重空间混合后，杠杆是 5.19，**降不下去了**。

原因：杠杆由 Σ 决定，μ 只决定方向。μ 再怎么修，杠杆就停在 Σ̃ 决定的那个水平上。

**写法**：不要写"再修 μ 杠杆继续降"。写"修 μ 不改变杠杆，改变的是夏普
（0.032 → 0.255）"。这个说法更准确，也更有解释力。

### ④ "两段数据答案就翻"是真的，但要看相关系数不是看图形

原方案说"换一段数据答案就翻"。本程序实测相关系数 **−0.03**、换手率 0.70。
这个数字比"翻"更精确，而且可以在图 5a 上逐条核对。

**另外**：图 5a 里两本书的权重绝对值能到 ±200% of NAV。原方案写的"±几百%"是对的，
但要说明这是**在 15% 波动目标下**的仓位，不是"权重和等于 1"的仓位。

### 8.2 每章的关键句（照这个骨架展开就不会散）

**第 2 章**
> 协方差矩阵不只是一个"风险的数字"，它是一个二次型的核。它把权重向量映成一个数，
> 而特征分解告诉我们这个二次型在哪些方向上"贵"、在哪些方向上"便宜"。

**第 3 章**
> 求逆就是把特征值取倒数。一个接近零的特征值，在求逆之后变成一个极大的数；
> 而估计误差恰好最容易出现在那些"看起来最便宜"的方向上——因为那里没有信息。

**第 4 章**
> 同一个市场、同一份数据长度，资产数从 5 增到 55，优化器要求的杠杆从 1.2 倍涨到 55 倍；
> 它以为自己跑的是 15% 波动的组合，真实波动是 212%。

**第 5 章**
> 病态性有两个症状：杠杆爆炸来自 Σ，方向错误来自 μ。收缩 Σ 修前者，收缩 μ 修后者，
> 两者不能互相替代。而当 T 只有 60 时，μ 那一半根本修不好——这就是 1/N 赢的原因。

**第 6 章**
> 数学上的最优是一个关于 Σ⁻¹ 的陈述。当 Σ 只能被估计时，"最优"这个词的含义
> 就从"收益最高"悄悄变成了"对误差最敏感"。

### 8.3 四个「必须有」的段落

1. **条件数与求逆的关系**（第 2 章，约 250 字）。要写清 ‖Σ⁻¹‖ = 1/λ_min，
   以及 κ 是"相对误差放大倍数"这件事，不能只给定义。
2. **一阶扰动推导**（第 3 章，约 350 字）。从 `Ŝx̂ = μ̂` 与 `Σx = μ` 两式相减出发
   （**不要从 `(Σ+δΣ)(x+δx) = μ+δμ` 出发**——那样推出来的是 κ(Σ)，和实测那一列对不上），
   得到 `x̂ − x = Ŝ⁻¹δμ − Ŝ⁻¹(δΣ)x`，再取范数、除以 ‖x‖，用 `‖μ‖ ≤ ‖Ŝ‖‖x‖` 收尾，
   常数落在 **κ(Ŝ)**。**这是全篇唯一一处真正的推导，必须自己写一遍。**
3. **为什么 Ledoit-Wolf 的 δ 不等于正则化强度**（第 5 章，约 200 字）。
   一个最小化 E‖Σ̃−Σ‖²，一个最小化求逆后的方差。这是"会用"和"抄公式"的分界线。
4. **均值 t 统计量那一段**（第 5 章，约 150 字）。中位数 |t|=0.66 说明什么，
   为什么它直接解释了 1/N 的胜利。

### 8.4 摘要模板（最后填数字）

> 本文以马克维茨投资组合优化为载体，研究协方差矩阵的病态性如何影响最优权重的可靠性。
> 首先由特征分解给出求逆的误差放大机制：‖Σ⁻¹‖ = 1/λ_min，一阶扰动下
> ‖δx‖/‖x‖ ≤ κ(Ŝ)(‖δμ‖/‖μ‖ + ‖δΣ‖/‖Σ‖)。其次在一个校准的三因子市场上做 30 次重复实验，
> 固定 60 个交易日的估计窗口，令资产数从 5 增到 55：样本协方差的条件数从 65 涨到 12804，
> 最小特征值只剩真值的 0.6%，而优化器要求的杠杆从 1.23 涨到 54.75，
> 其自认为的 15% 波动对应的真实波动为 212%；给 Ŝ 加 1% 的相对扰动，解的相对误差被放大 155 倍
> （1% → 155%）。
> 再次用"把一个矩换成真值"的方法划分责任：已知 μ 只估 Σ 时夏普为 0.253，
> 已知 Σ 只估 μ 时仅 0.028，而均值向量的相对估计误差是协方差的 21 倍。
> 最后比较两种修补：收缩 Σ 把杠杆降到 5.71 但不改善夏普（0.032），
> 沿权重空间收缩 μ 把夏普提到 0.255；即便如此，等权组合的 0.396 仍高于所有优化模型，
> 与 DeMiguel 等 (2009) 的结论一致。结果表明：协方差矩阵的病态性决定组合的风险尺度，
> 均值的不可估性决定组合的方向，二者需要分别处理。

## 9 公式清单

写作时这些公式必须出现，且符号要与代码一致（`w` 是权重，`Σ` 是协方差，`μ` 是期望收益，
`x = Σ⁻¹μ` 是未缩放的解，`κ` 是条件数）。

**① 马克维茨问题与解**
```
min_w  (1/2) wᵀΣw   s.t.  wᵀμ = μ_t,  1ᵀw = 1
⟹  w = Σ⁻¹(λ₁μ + λ₂1)
切点组合（不约束收益水平）：  x = Σ⁻¹μ,   w = x / (1ᵀx)
```

**② 特征分解与求逆**
```
Σ = VΛVᵀ = Σ_i λ_i v_i v_iᵀ,   λ_i > 0
Σ⁻¹ = VΛ⁻¹Vᵀ = Σ_i (1/λ_i) v_i v_iᵀ
‖Σ⁻¹‖₂ = 1/λ_min
```

**③ 条件数**
```
κ(Σ) = λ_max / λ_min = ‖Σ‖₂ ‖Σ⁻¹‖₂
```

**④ 一阶扰动（全篇核心推导）**

> ⚠️ 这一条**必须以 Ŝ 为基准展开**，不能以真 Σ 为基准。两者的 `δx` 同名不同义：
> 以 Σ 为基准推出来的是"真 Σ 被扰动后，精确解跟着变多少"（常数 κ(Σ)）；
> 实测量的是"用 Ŝ、μ̂ 算出来的解，离真解多远"（常数 κ(Ŝ)）。
> 论文要写的是后者，因为实测那一列比的就是后者。

```
Ŝ x̂ = μ̂ ,     Σ x = μ        （记 δΣ := Ŝ − Σ ,  δμ := μ̂ − μ）

x̂ − x = Ŝ⁻¹μ̂ − x
      = Ŝ⁻¹(μ + δμ) − x
      = Ŝ⁻¹(μ − Ŝx) + Ŝ⁻¹δμ
      = −Ŝ⁻¹(δΣ)x + Ŝ⁻¹δμ

⟹  ‖x̂ − x‖ ≤ ‖Ŝ⁻¹‖ ( ‖δμ‖ + ‖δΣ‖‖x‖ )

⟹  ‖δx‖/‖x‖ ≤ κ(Ŝ) ( ‖δμ‖/‖μ‖ + ‖δΣ‖/‖Ŝ‖ )
```

中间那步用 `μ − Ŝx = (Σ − Ŝ)x = −δΣ·x`；最后一步把 `‖δμ‖/‖x‖` 用 `‖μ‖ ≤ ‖Ŝ‖‖x‖`
换成 `‖δμ‖/‖μ‖`，于是前面的 `‖Ŝ⁻¹‖` 凑成 `κ(Ŝ) = ‖Ŝ⁻¹‖‖Ŝ‖`。

**论文正文统一写这一条**（分母用 ‖Σ‖，与表 5 的 ε_Σ 同口径）：

```
‖δx‖/‖x‖ ≤ κ(Ŝ) ( ‖δμ‖/‖μ‖ + ‖δΣ‖/‖Σ‖ )
```

> 为什么可以从 ‖Ŝ‖ 换成 ‖Σ‖：只多出一个 `‖Ŝ‖/‖Σ‖` 的因子，实测 30 次重复平均
> **1.04（±0.15）**，并进常数即可，不影响 0.011 这个结论。
> 之所以统一用 ‖Σ‖：① 程序里 `relative_error` 就是除以真值范数；
> ② 表 5 的 ε_Σ 本身就是 `‖Ŝ−Σ‖_F/‖Σ‖_F`，引用它必须同口径；
> ③ 读者拿 1248 和 8.67 验算 0.011 时，用的正是 ‖Σ‖。
> **全文只出现这一个写法**，上面那个 ‖Ŝ‖ 形式只作为推导的中间产物，不进正文。

**为什么不能写 κ(Σ)**：以真 Σ 为基准，常数必然是 κ(Σ)=65，代进实测会得到
1248/(65×8.67)=2.2>1，界直接被违反。κ(Σ) 说的是"真矩阵有多病态"，
κ(Ŝ) 说的才是"你实际求逆的那个矩阵有多病态"——决定误差的是后者。

**⑤ 特征方向分解**
```
x = Σ⁻¹μ = Σ_i c_i v_i,   c_i = (v_iᵀμ)/λ_i
```
（这条把"求逆放大"翻译成"某个方向上的仓位爆炸"，是全篇最直观的一行。）

**⑥ Ledoit-Wolf 收缩**
```
Σ̃ = (1 − δ) Ŝ + δ · (tr(Ŝ)/N) I
δ* = clip( (π̂ − ρ̂) / (T γ̂), 0, 1 )
γ̂ = ‖Ŝ − mI‖_F²,   m = tr(Ŝ)/N
```

**⑦ 波动率目标缩放**
```
w_scaled = w · σ_target / √(wᵀΣw)      （年化：σ_target = 15%）
杠杆 = ‖w_scaled‖₁
```

**⑧ 夏普比**
```
SR(w) = (wᵀμ) / √(wᵀΣw) · √252
```
（注意它是**缩放不变**的，所以波动率目标不会影响夏普的比较。）

**⑨ 均值的 t 统计量**
```
t_i = μ̂_i / (s_i / √T)
```

**⑩ Marchenko-Pastur 参考（第 3 章用）**
```
κ_MP = ((1 + √(N/T)) / (1 − √(N/T)))²,   N < T
```

## 10 避坑清单

1. **不要用"权重和为 1"定义杠杆。** 它要除以 1ᵀΣ⁻¹μ，那个标量会随机穿零，
   单次抽样的杠杆不可复现。用波动率目标。
2. **不要用单次抽样下结论。** 同一个设定换一段数据，夏普能跳 ±0.15，
   和要测的效应一样大。必须 30 次重复取均值，并在图上画 ±1 标准差。
3. **不要混用"真值"和"估计值"。** 优化器只能看到 μ̂ 和 Ŝ；
   真值只用于评估。混一次，全篇结论作废。
4. **不要把 Ledoit-Wolf 的 δ 当成正则化强度。** 它的目标是估计精度，不是求逆稳定性。
   这个区别要写进第 5 章。
5. **不要写"再修 μ 杠杆继续降"。** 杠杆由 Σ 决定，修 μ 改的是夏普。
   写错这一句，第 4 章的两个结论就串了。
6. **不要把均值收缩写成"朝截面均值收缩"就完事。** 要交代 T=60 时截面均值可能是负数，
   以及为什么改用权重空间的凸组合（见 §4 e4(b)）。
7. **图里不要写中文。** 本机 matplotlib 没有中文字体，会变方块。
   图里全用英文，图题在正文里用中文写。
8. **每张图后面至少 100 字解释**，并且正文要引用（"如图 3 所示"）。
   只贴图不说话，图文比例失衡。
9. **所有数字从 `outputs/report.md` 抄**，不要凭记忆写，更不要抄《选题确认.md》
   里的旧数字（那是一次抽样、另一套口径）。图、表、正文三处必须一致。
10. **不要写成"线性代数在 N 个金融问题上的应用"。** 出现"此外，线性代数还可用于……"
    立刻删掉。全篇只有一个载体：一次组合优化。

## 附：换成真实数据怎么做

程序默认用模拟市场（理由见 §1）。若想换成真实收益率序列：

1. 准备一个 `T × N` 的日收益率矩阵（每列一个资产，已去均值或不去都可以），
   存成 csv；
2. 在 `src/market.py` 里加一个 `load_csv(path)`，返回
   `Market(mu=样本均值, cov=样本协方差, ...)`。注意此时 `Σ_true` 未知，
   **e1/e3/e5 里依赖真值的部分（真实夏普、责任划分、上帝视角）将不可用**，
   只能保留 e2（杠杆）和 e4（收缩路径）；
3. 其余代码不用改。

换句话说：**这个程序的完整结论只在有真值时才成立**，这也是它用模拟市场的原因。
真实数据能验证"杠杆爆炸"和"收缩有效"，但验证不了"离真值多远"。
